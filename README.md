# Bare Beauty by Ionee

Website, online booking and a private studio panel for Bare Beauty by Ionee. Runs free on Netlify (static site, Netlify Functions, Netlify Blobs for data), with her Instagram posts on the home page and privacy, booking terms and accessibility pages built in.
